# מחדש את החווייה — תוכנית רי־עיצוב מלאה

> הוחלף בגרסה 3.0 ("Clear View"). ראו README. המסמך נשאר לתיעוד היסטורי.

תאריך: 16.9.2026 · סטטוס: מומש (גרסה 2.0)
ענף: `redesign` · גיבוי: תגית `backup/pre-redesign`

## 1. מה היה

- 6 מסכים (בית, הקלטות, אנשים, עקרונות, חיפוש, מעקבים) ב-hash routing.
- **אין מסכי פנים**: קרס פגישה לא לחיצה, אין פרופיל אדם, אין קורא תמלול.
- חיפוש נאיבי: התאמה של המילה הראשונה ל־JSON של הפגישות בלבד.
- המצג כרטיסים אחידים; פונט Arial; סרגל צד כהה + זהב; hero עם גרדיאנט.
- נתונים: `meetings / people / principles / followups` ב־localStorage (`consultingKnowledge`) + SEED מקומי.

## 2. מה נשמר (בלי שינוי)

| רכיב | סטטוס |
|---|---|
| מפתח localStorage, מבנה הנתונים, SEED | לא נגע |
| 6 המסכים הקיימים (hash routes) | עובדים כפי שהיו, כולל back-compat של `#home` |
| זרימת ייבוא PLAUD (שם/אדם/תאריך/הדבקה/קובץ) | אותם שדות, אותה התנהגות (עדכון people, יצירת מעקב אוטומטית) |
| `document.modelContext.registerTool` — `search_consulting_knowledge` ו־`create_follow_up` | שמות/סכמות זהות; החיפוש רחב יותר (כל 4 האוספים) |
| PWA: manifest + Service Worker | שוערוד לסכמת v2 עם runtime-cache לגופנים |
| RTL, עברית, offline | נשאר; גופנים מטופלים ב-fallback |

## 3. ארכיטקטורת מידע חדשה

```
בית                     dashboard ממוקד (ללא vanity stats)
הקלטות        ──→  case/:id      מקרה (המסך המרכזי)
אנשים          ──→  person/:name  פרופיל אורך (הזיכרון לפני הפגישה)
עקרונות        ──→  principle/:id עיקרון (המתודולוגיה)
חיפוש          ← ⌘K palette + hero + search page
מעקבים         (קבוצה לפי אדם, overdue, toggle)
```

עקרונות:
1. כל רכיב ידע עם זהות משלו (פגישה ≠ אדם ≠ עיקרון) וקפיצה ישירה ביניהם.
2. **שאלה חופשית היא citizen first-class**: ⌘K בכל מסך, hero בבית, שדה דומיננטי במסך החיפוש.
3. שרשרת הלוגיקה `בעיה → תצפית → נימוק → עצה → תוצאה מצופה` היא גיבור המסך `case`.
4. עובדה מפורשת מול ממצא נלמד — תמיד מובחנות ויזואלית; ביטחון מוצג בעדינות (meter + תווית), לא כבאדג' צעקני.
5. עיקרון "מועמד שמנוסח מן הפרקטיקה" מופרד ויזואלית מ"הקבילה אקדמית/מחקרית שAI מציגה" (data-driven; ה־SEED הוא פרקטיקה).

## 4. שפת העיצוב — "Calm Intelligence"

- **גופנים**: Heebo (UI, 300–700) · Frank Ruhl Libre (כותרות, הצהרות, ציטוטי תמלול — נגיעת הספרייה) · IBM Plex Mono (חותמות זמן, מטא־נתונים).
- **פלטת אור** (ברירת מחדל) — עור-נייר + יוקרתי-טקטילי:
  - paper `#F4F2EC` · surface `#FFFFFF` · ink `#1B2129` · muted `#6E6A5E` · line `#E3DFD4`
  - accent (petrol, המשך המותג) `#0E5E56` · evidence-gold `#96690F`/`#F3E8D2` · alert `#9A3B30`
- **מצב כהה** (toggle, נשמר): `#101418`/`#161B21`, teal בהיר, gold חם. מוצע למשבצות ארוכים.
- **צפיפות**: בסיס 14px, line-height 1.55–1.7 לקריאה, hairline dividers במקום borders, radius 10–12, צל רק ב-popovers/dialogs.
- **RTL נטיבי**: CSS logical properties בכל המקום; חיצ' "המשך" מצביע שמאלה; חותמות זמן ב־`dir="ltr"` mono.
- **נגישות**: skip link, aria-current, focus-visible, aria-live, `prefers-reduced-motion`, קונטרססט AA, גוון כהה בהירות.

## 5. המסכים

### 5.1 בית (dashboard שימושי)
חיפוש מרכזי (hero) + שורת מטא שקטה (פגישות · אנשים · עקרונות · מעקבים פתוחים — טקסט לחיצה, לא כרטיסי סטטיסטיקה) · "דורש מעקב" · "פגישות אחרונות" · "עקרונות עם ביטחון גבוה".

### 5.2 מקרה `case/:id` — המסך המרכזי
- כותרת + שורת מטא: אדם (קישור) · תאריך · מקור ההקלטה · טווח זמן · תגים.
- סיכום הפגישה.
- **שרשרת ויזואלית** (spine אנכי, צעד ממוספר + label): בעיה → תצפיות → הנימוק → **העצה** (בלוק מדגיש — ה"payload") → תוצאה מצופה → מעקבים. כל פריט: תג `מופיע במפורש` / `נלמד מן הטקסט`, ביטחון עדין, and link "ציון מקור" שקופץ לתמלול ומדגיש.
- חריגים וניגודויות (empty state כש אין).
- עקרונות רלוונטיים (kishur heuristi, מסומן "עשוי להתייחס").
- **קורא תמלול** (panel צדדי sticky; במובייל מתחת): שורה-שורה עם דובר, חותמת זמן, חיפוש בתוך התמלול, רצועות "עדות" בעלות tint, flash highlight לקפיצה מהניתוח.

### 5.3 פרופיל אדם `person/:name`
"הזיכרון לפני הפגישה": כותרת + נושא · מעקבים פתוחים (overdue בולט) · היסטוריית עצות (אשר נתנו, למה, ביטחון, קישור למקרה) · דפוסי בעיות חוזרים (tags) · עקרונות רלוונטיים · ציר זמן של כל הפגישות.

### 5.4 עקרונות
קצת קארדים: type-badge (פרקטיקה vs הקבילה אקדמית — צבעים שונים, הבהרה שמדובר בהקבילה AI ולא בשיטת היועץ) · הצהרה serif · סטטיסטיקות (הופעות, תוצאות חיוביות, meter ביטחון). פנים: מקרים תומכים, חריגים, עקרונות קרובים, התפתחות לאורך זמן — כולם empty states כנים בהיעדר נתונים.

### 5.5 הקלטות
רשימה צפופה קבוצה לפי חודש; כל שורה: תאריך · כותרת · אדם · תגים · סיכום · "N מקרים זוהו". (הסכמה תומכת בריבוי מקרים בהקלטה; כרגע 1.)

### 5.6 מעקבים
קבוצה לפי אדם; due עם relative label (היום/מחר/עברו X ימים); overdue ב-alert; toggle שמירה; כפתור יצירה מהירה.

### 5.7 חיפוש (⌘K + מסך)
- Palette: ⌘K / Ctrl K בכל מסך, חיפוש חי, ניווט מקלדת (↑↓ Enter), recent searches + דוגמאות.
- מנוע (rule-based, אונליין): tokenize + stoplist עברית, תעדיפות שדות (title/tags/summary > transcript), soft-AND, question-verb boost ("מה ייעצתי…" מעדיף עצה), snippet עם `<mark>`, results group לפי סוג.

## 6. אנליזה מקומית (הרחבת ה-pipeline הקיים)

`analyzeTranscript(text)` — pure function:
- פירוק לשורות/משפטים; זיהוי דובר (`שם: …`) וחותמות זמן (`[hh:mm:ss]`) כשהם קיימים.
- סיווג סטטיסטי (regex מיוקד עברית): advice / decision / rationale / problem / observation / follow-up / contradiction / outcome.
- כל פריט נושא `kind: explicit|inferred` + `confidence` (heuristi לא עולה על 90 — כן) + `evidence: {quote, time, speaker, seg}`.
- מיושם על SEED וייבואים חדשים באותו קווי ייצור — **אין נתון mock**; מה שרואים במסכים הוא תוצר ה־pipeline על הטקסטים הקיימים.
