# מאגר הייעוץ

PWA בעברית לניהול הידע המצטבר מפגישות ייעוץ: תמלולים, אנשים, עקרונות, מעקבים וחיפוש חופשי.

## גרסת ה-MVP

- לוח עבודה מותאם לאייפון ולמחשב
- ייבוא תמלול מ-PLAUD באמצעות הדבקה או קובץ טקסט
- חילוץ מקומי ראשוני של אנשים, החלטות, עקרונות ומעקבים
- חיפוש חופשי בכל המידע
- מסכי הקלטות, אנשים, עקרונות ומעקבים
- שמירה מקומית בדפדפן ונתוני הדגמה
- התקנה באייפון דרך „הוסף למסך הבית”

> זהו אב-טיפוס מקומי. לפני שימוש במידע אמיתי ורגיש יש לחבר מסד נתונים מאובטח, אימות משתמש והצפנה.

## הפעלה מקומית

האתר סטטי. אפשר להגיש את תיקיית `dist` מכל שרת קבצים, למשל:

```bash
python3 -m http.server 4173 --directory dist
```

ואז לפתוח `http://localhost:4173`.
