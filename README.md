# מאגר הייעוץ

PWA בעברית לניהול הידע המצטבר מפגישות ייעוץ: תמלולים, אנשים, עקרונות ומעקבים — כ"מוח שני" ליועץ.

## גרסת 2.0 — חווייה מלאה

- **מסך מקרה (`#/case/:id`)** — שרשרת ההסקה המלאה: בעיה → תצפיות → נימוק → עצה → תוצאה מצופה → מעקבים, עם הבחנה בין "מופיע במפורש" ל"נלמד מן הטקסט", ביטחון עדין וקפיצה לציון המקור בתמלול.
- **קורא תמלול** — דוברים, חותמות זמן (כשהן קיימות), מסמני "עדות" לפסקאות שעליהן מבוסס הניתוח, חיפוש בתוך התמלול והדגשת קפיצה.
- **פרופיל אדם (`#/person/:name`)** — הזיכרון לפני הפגישה: מעקבים פתוחים, היסטוריית עצות ונימוקים, דפוסי בעיות, עקרונות רלוונטיים וציר זמן.
- **עקרונות (`#/principles`, `#/principle/:id`)** — מתודולוגיה שמנוסחת מההקלטות: ביטחון, הופעות, מקרים תומכים, חריגים, עקרונות קרובים והתפתחות לאורך זמן. הערה קבועה מפרדת בין עיקרון "מן הפרקטיקה" לבין "הקבילה מחקרית שאי־AI מציע".
- **חיפוש מרכזי** — פלטת ⌘K / Ctrl K (או `/`) בכל מסך, hero חיפוש בבית, ומסך חיפוש מלא עם תוצאות מקובצות, סינון ודגימת התאמות. מנוע מקומי rule-based על אדם, נושא, עצה, נימוק, תמלול, עיקרון ומעקב.
- **דשבורד שימושי** — דורש מעקב (כולל overdue), פגישות אחרונות, עקרונות עם ביטחון גבוה.
- **מעקבים** — קבוצה לפי אדם, תאריכי פקיעה עם "היום/מחר/עברו X ימים", טופס יצירה מהירה.
- **מצב כהה/בהיר** (נשמר), RTL נטיבי, גופנים Heebo + Frank Ruhl Libre + IBM Plex Mono, נגישות (skip link, aria, focus-visible, reduced-motion).
- ייבוא תמלול מ-PLAUD (הדבקה או קובץ TXT) עם ניתוח מקומי מובנה — **הנתונים אינם עוזבים את המכשיר**.

### קיצורי מקלדת

| קיצור | פעולה |
|---|---|
| `⌘K` / `Ctrl K` | פתיחת החיפוש המרכזי |
| `/` | פתיחת החיפוש המרכזי (כשלא בשדה) |
| `↑` `↓` + `Enter` | ניווט בתוצאות הפלטה |

## הפעלה מקומית

האתר סטטי:

```bash
python3 -m http.server 4173 --directory dist
```

ואז לפתוח `http://localhost:4173`.

> חיוני להפעיל דרך HTTP (PWA, Service Worker, גופני CDN). פתיחה דרך `file://` לא תעבוד במלואה.

## מבנה

```
dist/                # האפליקציה (מקור הפרסום)
docs/                # מראה של dist/ + תיעוד (architecture.md, redesign.md)
supabase/schema.sql  # סכמת PostgreSQL לשלב המחובר
```

## השלב הבא

הארכיטקטורה המיועדת לגרסה המחוברת מתועדת ב-[docs/architecture.md](docs/architecture.md), ותוכנית הרי־עיצוב המושלמת ב-[docs/redesign.md](docs/redesign.md). סכמת PostgreSQL ראשונית נמצאת ב-[supabase/schema.sql](supabase/schema.sql).
