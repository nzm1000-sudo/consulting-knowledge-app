# מאגר הייעוץ

אפליקציית PWA בעברית שמשמשת זיכרון מקצועי ליועץ: הקלטות, אנשים, עצות ונימוקים, עקרונות, חריגים ומעקבים.

> זו גרסת הדגמה ציבורית עם נתונים סינתטיים בלבד. המערכת המבצעית רצה על ה־NAS ואינה חלק מהמאגר הזה. אין להעלות לכאן תמלולים אמיתיים, מפתחות או פרטי תשתית.

## גרסה 3.5 · מוניטור דופק

- מתחת לכותרת הבית: מוניטור דופק עם צורת פעימה אמיתית (גל P, קומפלקס QRS, גל T). ראש כתיבה זוהר נע מימין לשמאל, סבב מלא ב־9.6 שניות, ומשאיר שובל זרחני שדוהה. לפני הראש יש רווח מחיקה, כמו במוניטור אמיתי. קו שני, דק ועדין, בצבע המשני של הפלטה, ורשת מדידה דקה שדוהה לכיוון הקצוות.
- פעימה כל 4.8 שניות, בתיאום עם שאר הדופק באתר. במצב תנועה „עדינה” הקו מוצג בלי תזוזה.
- כל התנועה באתר הואטה: רקע במחזור של דקה וחצי, טווחי תזוזה קטנים.

## גרסה 3.3 · שכבה חיה

- רקע גרפי חי (canvas): רשת נקודות ידע שמתחברות ביניהן, אלומות אור שנעות לאט, ומקור אור שעוקב אחרי הסמן. הרשת פועמת בקצב לב.
- צללים דינמיים: הצללים של הכרטיסים נופלים בכיוון ההפוך למקור האור.
- טבעת אור שמסתובבת לאט סביב שדה החיפוש.
- מתג „תנועה” בתפריט: מלאה, עדינה (אור ונשימה בלי תזוזה), כבויה. ברירת המחדל עדינה כשבמכשיר מוגדרת הפחתת תנועה.

## גרסה 3.2 · פלטות ותנועה

- חמש פלטות צבעים לבחירה מהתפריט, כל אחת במצב יום ובמצב לילה: טורקיז, ניאון (ורוד זוהר, סגול, כתום וירוק), אוקיינוס, שקיעה ויער. הבחירה נשמרת.
- תנועה רכה: זוהר רקע שנע לאט, סמל שנושם, נקודות „חי” שפועמות כמו דופק, כרטיסי נתונים שמרחפים, וכניסה מדורגת של תוכן בכל מעבר מסך. הכול כבוי למי שהגדיר הפחתת תנועה.

## גרסה 3.1 · Clear View · Depth

עומק ותאורה: רקע עם זוהר צבעוני עדין ורשת דקה, משטחים של זכוכית חלבית, צללים בשכבות שגדלים במעבר עכבר, והטיה תלת־ממדית עדינה בכרטיסי העקרונות. פלטה מורחבת: טורקיז ואינדיגו כצבעי מותג, וגוון נפרד לכל סוג ידע (בעיה, תצפית, עצה, נימוק, תוצאה מצופה, מה קרה, מעקב, חריג). כותרות בגופן Rubik.

### פריסה
- שלוש עמודות: ניווט, אזור עבודה, ולוח הקשר שמשתנה לפי המסך.
- לוח ההקשר מציג בהקלטה את פרטיה, פגישות נוספות עם אותו אדם, מעקבים פתוחים ועקרונות אפשריים. בפרופיל אדם הוא מציג מעקבים, נושאים חוזרים ועקרונות.
- זמני היום לנתיבות: תאריך עברי, עלות השחר, הנץ, סוף זמן ק״ש ותפילה (גר״א), חצות, שקיעה וצאת הכוכבים. חישוב אסטרונומי מקומי (NOAA), מתעדכן כל דקה.
- טקסט מקור (תמלול, PLAUD, ציטוט עדות) מוצג בגופן סריף. טקסט של המערכת מוצג בגופן רגיל. כך ברור תמיד מה נאמר ומה הוסק.

### מסכים
| מסך | route | מה יש בו |
|---|---|---|
| היום | `#home` | חיפוש, מעקבים שדורשים טיפול, הקלטות ועצות אחרונות, גיבוי |
| הקלטות | `#recordings` | סינון לפי טקסט ואדם, סימון ההקלטה שנפתחה לאחרונה |
| הקלטה | `#/case/:id` | לשוניות: ידע שחולץ, תמלול מקור, ניתוח PLAUD |
| אנשים | `#people`, `#/person/:name` | „מה השתנה מאז הפגישה הקודמת”, כל העצות, ציר זמן |
| מעקבים | `#followups` | קבוצות לפי אדם, איחורים, קישור להקלטת המקור |
| עצות ונימוקים | `#advice` | כל עצה עם הנימוק, האדם, ההקלטה וציון המקור |
| עקרונות | `#principles`, `#/principle/:id` | מקרים מקושרים וחריגים. הקישור הוא השערה לפי חפיפת מילים |
| סתירות וחריגים | `#contradictions` | חריגים שנאמרו, ועצות שהשתנו אצל אותו אדם |
| חיפוש | `#search`, `Ctrl K`, `/` | תחיליות (ו/ה/ב/ל/מ/ש/כ), מילים נרדפות, תוצאות מקובצות |

### ראיות
כל פריט ידע נושא `kind` (נאמר במפורש או הסקה של המערכת), רמת ביטחון, והפניה למשפט המקורי. הכפתור „למה?” מציג את המשפט, ו„פתיחה בתמלול” קופץ אליו ומדגיש אותו.

### שמירת מצב
המסננים, הלשונית הפתוחה בכל הקלטה, מיקום הגלילה בכל רשימה וההקלטה האחרונה שנפתחה נשמרים לאורך הסשן.

### נתונים
- הכול נשמר ב־`localStorage` במפתח `consultingKnowledge`.
- **גיבוי ושחזור**: קובץ JSON מהתפריט. מסך הבית מזכיר אם לא נשמר גיבוי 7 ימים.
- מחיקת הקלטה מלוח ההקשר.
- הניתוח מסומן בגרסה (`ANALYSIS_VERSION`). כששיפור בכללים משנה את הגרסה, כל ההקלטות מנותחות מחדש בטעינה.
- ה־Service Worker עובד ב־network first, כך שעדכון מגיע למשתמשים בטעינה הבאה.

## הפעלה מקומית

```bash
python3 -m http.server 4173 --directory dist
node test/smoke.mjs
```

`dist/` הוא המקור. `docs/` הוא העותק ש־GitHub Pages מגיש, ומתעדכן בהעתקה:

```bash
for f in index.html styles.css app.js sw.js manifest.webmanifest favicon.svg; do cp dist/$f docs/$f; done
```
